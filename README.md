# HeStrong Word Flip

一个极简的背单词闪卡网页，纯前端实现，打开就能用。

## 功能（MVP）
- 🃏 闪卡翻面：正面英文，点击看中文释义
- ✅ 认识 / ❌ 不认识：认识的过掉，不认识的本轮重复出现
- 📊 进度记录：自动保存在浏览器里，下次接着背
- 📚 内置 300 个高频英语词汇

## 使用方法
在线版（GitHub Pages）：<待部署后填入链接>

本地运行：直接用浏览器打开 `index.html` 即可，不需要任何服务器。

## 词库
词库在 `words.js` 里，格式很简单：

```js
{ word: "abandon", meaning: "v. 放弃；遗弃" }
```

想加词直接往数组里追加一行就行。
