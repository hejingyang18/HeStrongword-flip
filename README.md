# HeStrong Word Flip

一个极简的背单词闪卡网页，纯前端实现，打开就能用,无需下载。

## 功能（MVP）
- 🃏 闪卡翻面：正面英文，点击看中文释义
- 🎯 闯关模式：按难度分 5 关，每关正确率超过 90% 解锁下一关
- 🔓 进度保存：通关进度与各关最佳正确率自动存在浏览器里
- 🔊 发音：Web Speech API 朗读单词
- 🌙 深色模式
- 📚 内置 300 个高频英语词汇

## 使用方法
在线版（GitHub Pages）：https://hejingyang18.github.io/HeStrongword-flip/

本地运行：直接用浏览器打开 `index.html` 即可，不需要任何服务器。

## 词库
词库在 `words.js` 里，格式很简单：

```js
{ word: "abandon", meaning: "v. 放弃；遗弃" }
```

想加词直接往数组里追加一行就行。

## 闯关规则
- 词库按数组顺序粗略切成 5 关（热身 / 进阶 / 提高 / 高阶 / 挑战），每关约 60 词。
- 每关把本关所有词过一遍，点「认识」/「不认识」，不认识的词本轮会再出现。
- 首答正确率（首次作答就点「认识」的比例）超过 90% 即通关，解锁下一关。
- 通关后可按「下一关」继续，未通关可按「重玩本关」再挑战。
- 词库暂无逐词词频数据，若想按真实词频调整难度，先把 `words.js` 里的词按词频重排即可。
